# Скилл: сравнительная таблица кандидатов

Одна задача: положить уже разобранных кандидатов в одну таблицу по критериям вакансии.

> Сравнение не заменяет скрининг. Если статусов по требованиям ещё нет, сначала разложи каждого отдельно.

## Когда применять

- Кандидатов двое или больше.
- Есть общий список критериев из вакансии.
- По каждому уже понятно, что видно в резюме, или ты готов пройти критерии заново по правилам скрининга.

## Когда не применять

- Кандидат один.
- Критериев нет.
- Просят «кто лучше как человек», «кто приятнее» или «кого бы вы наняли» без линейки.

## Входы

- Список критериев: обязательные и желательные, помеченные.
- Материалы по каждому кандидату.
- Имена можно сократить до инициала. Контакты в таблицу не ставить.

## Выход

Одна таблица: строки — критерии, столбцы — кандидаты, последняя строка — что сделать человеку (слот интервью, один вопрос, не тратить слот).

Короткий вывод на 3–5 строк. Без рейтинга «место в топе», если числа не заданы.

## Шаги

1. Выпиши критерии. Обязательные наверху, желательные ниже.
2. Заполни клетки только фактами: «да + цитата», «не видно», «нет, есть цитата об обратном», «ниже порога».
3. Не ставь желательное выше проваленного обязательного.
4. Не усредняй «в целом сильный».
5. В последней строке для каждого — одно действие, а не характеристика.
6. Если данных не хватает на клетку, оставь «не видно» и вопрос. Не заполняй клетку догадкой, чтобы таблица выглядела полной.

## Шаблон

| Критерий | Кандидат А | Кандидат Б |
| --- | --- | --- |
| Обязательное: … |  |  |
| Желательное: … |  |  |
| Что сделать | слот / вопрос / не звать |  |

## Пример

Критерии: первичка от 2 лет (обязательно, стоп-фактор), 1С (обязательно), сверка с контрагентами (желательно).

- А.: первичка 4 года, 1С есть, сверка есть → в первую очередь на интервью.
- Б.: первичка 1 год, 1С не видно → один вопрос про программу, не отказывать из-за желательного.
- В.: первички нет → слот не занимать.

## Не делать

- Не писать «культурный», «стрессоустойчивый», «наш человек», если этого не было критерием.
- Не вычитать баллы, если шкала не задана.
- Не рекомендовать оффер.
- Не подтягивать факты из одного резюме в другое.

## Как проверить

Два кандидата, у одного провал обязательного и красивое желательное. Желательное не должно его спасти.
