# Скилл: проверка первички

Одна задача: проверить, хватает ли на документе обязательных полей, прежде чем нести его дальше.

> Список полей ниже общий, не внутренний стандарт организации. Подставьте свой перечень. Скилл не принимает документ к учёту.

## Когда применять

- Есть скан, фото или текст первичного документа: акт, накладная, счёт-фактура, универсальный документ.
- Нужно сказать, какие обязательные поля видны, а каких не видно.
- Человек дал список обязательных полей или согласился на общий список из этого файла.

## Когда не применять

- Просят «принять к учёту» или провести.
- Документа нет, есть только пересказ.
- Список полей ваш и он не приложен, а общий список вы использовать запретили. Тогда остановись и попроси список.

## Входы

- Документ.
- Список полей. Если его нет, используй общий и подпиши: «общий учебный список, замените на свой».

Общий список: название документа, дата, номер, кто оформил, кому, что поставлено или сделано, сумма, подписи и должности.

## Выход

Таблица: поле, что видно в документе, статус `есть` / `не видно` / `пусто`.

Внизу: можно ли нести дальше по этому списку. Если хоть одно обязательное поле «не видно» или «пусто» — ответ «рано», без сглаживания.

## Шаги

1. Иди по списку полей, не оценивай документ «в целом аккуратный».
2. «Есть» ставь, только если значение видно. Коротко перепиши его.
3. Подпись, которую не разобрать, — «не видно», не «подпись есть».
4. Не дорисовывай реквизиты по названию контрагента из другого файла.
5. Не исправляй дату и сумму. Если они странные, пометь «проверить человеку», но не подменяй.
6. Итог «рано» или «поля из списка видны». Вторая фраза не значит «проводите».

## Шаблон

| Поле | Что видно | Статус |
| --- | --- | --- |
| Дата |  | есть / не видно / пусто |
| Сумма |  |  |
| Подпись |  |  |

```
Итог по списку: поля видны / рано нести дальше
Кто решает дальше: человек
```

## Пример

На скане есть название «акт», дата, стороны и сумма. Блок подписи обрезан. Статус подписи: не видно. Итог: рано нести дальше.

## Не делать

- Не писать «документ правильный».
- Не восстанавливать обрезанное «по смыслу».
- Не проводить и не ставить галочку учёта.
- Не использовать этот общий список как будто он ваш норматив, если у вас другой перечень. Пометь, что список учебный.

## Как проверить

Один полный учебный документ и один с обрезанной подписью. Второй не должен получить итог «можно нести».
