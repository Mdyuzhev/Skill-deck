# Скилл: сводка расходов

Одна задача: собрать строки расходов в статьи и показать, что выбивается. Не придумывать причины.

> Суммы учебные. Статья берётся из колонки, которую вы уже ведёте, или спрашивается. Скилл не закрывает период и не объясняет рост «потому что сезон», если этого нет во входе.

## Когда применять

- Есть таблица трат за период: дата, сумма, описание, по возможности статья.
- Нужна сводка по статьям и список необычных строк.
- Есть с чем сравнить (прошлый период) или хотя бы порог, что считать выбросом. Если порога нет, не объявляй выброс сам: покажи крупнейшие строки и спроси правило.

## Когда не применять

- Просят объяснить руководству, «почему так вышло», без фактов.
- Просят перенести расходы в учёт.
- Строк нет, есть одна цифра «всего».

## Входы

- Таблица трат.
- Справочник статей, если описания надо разложить по статьям. Без справочника группируй только по уже заполненной колонке «статья». Пустую статью клади в «не разнесено», не угадывай.
- Прошлый период или правило выброса, если нужно сравнение.

## Выход

1. Сводка: статья, сумма, доля.
2. Список «не разнесено».
3. Сравнение с прошлым периодом только по тем статьям, где есть оба числа.
4. Строки-выбросы по вашему правилу. Рядом сумма, дата, описание. Причина — только если она написана во входе.

## Шаги

1. Отсей пустые суммы и напиши, сколько строк пропущено.
2. Сложи по статьям. Строку без статьи не запихивай в «прочее» молча.
3. Посчитай доли от суммы разнесённых. «Не разнесено» покажи отдельно, не смешивай с «прочим».
4. Сравни с прошлым файлом статью к статье. Нет прошлого числа — не пиши «выросло».
5. Выброс помечай только по правилу из входа («больше N» или «рост больше чем вдвое»). Правило напиши в шапке ответа.
6. Не добавляй причину. Можно оставить пустое поле «комментарий человека».

## Шаблон

| Статья | Этот период | Прошлый | Комментарий человека |
| --- | --- | --- | --- |
|  |  |  |  |

```
Не разнесено:
Правило выброса:
Строки под правило:
```

## Пример

Командировки 780, канцелярия 220, связь 140, без статьи 460 — все числа в тысячах и учебные. 460 остаётся в «не разнесено». Если правила выброса не дали, крупнейшая строка показывается как кандидат на просмотр, без слова «аномалия» и без причины.

## Не делать

- Не выдумывать статью по описанию «как тебе кажется».
- Не объяснять рост догадкой.
- Не прятать неразнесённое внутрь «прочего».
- Не закрывать месяц формулировкой «сводка готова к защите».

## Как проверить

Десять строк, две без статьи, и прошлый период только по одной статье. Сравнение должно появиться только у этой статьи.
