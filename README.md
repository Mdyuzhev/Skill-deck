# Скиллы для ИИ-агентов

Часовая лекция для сотрудников бэк-офиса: что такое скилл, чем он отличается от разового промпта и как собрать папку под кадровые, документные и финансовые задачи.

Живой адрес после включения GitHub Pages: <https://mdyuzhev.github.io/Skill-deck/>

Слайды листаются стрелками, пробелом, кликом по краю экрана и свайпом. Номер слайда пишется в адрес: `#12` открывает двенадцатый. Раздатка для печати — [шпаргалка](cheatsheet.html). Готовые тексты скиллов — в [`templates/`](templates/).

## Что внутри

| Файл | Зачем |
| --- | --- |
| `index.html` | 43 слайда |
| `deck.js` | Масштаб 16:9, навигация, шаги на слайде, адрес `#N` |
| `styles.css`, `fonts.css`, `fonts/` | Оформление и шрифты с кириллицей, без запроса к Google |
| `cheatsheet.html` | Страница, которую удобно распечатать |
| `templates/*.md` | Шаблоны скиллов и чек-лист |
| `.github/workflows/pages.yml` | Публикация на GitHub Pages |

Сборки нет: это статические файлы. Открыть локально можно так:

```bash
python3 -m http.server 8765
```

Дальше в браузере: <http://127.0.0.1:8765/#1>

Файл `index.html` можно открыть и напрямую. Сервер нужен, только если браузер режет скрипты с диска.

## Как включить GitHub Pages

Репозиторий публичный, исходники лежат в корне `main`. Включить публикацию можно только в настройках GitHub, из самого репозитория это не включается.

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** поставьте **Source: GitHub Actions**.
3. Не выбирайте одновременно «Deploy from a branch»: иначе два способа будут публиковать сайт по очереди.
4. Если среда `github-pages` попросит разрешение при первом запуске, подтвердите его.
5. Запуск сам стартует на push в `main`. Если первый запуск успел упасть до включения Pages, откройте **Actions** → **Deploy GitHub Pages** → **Run workflow**.
6. Через минуту сайт будет на <https://mdyuzhev.github.io/Skill-deck/>.

Workflow выкладывает корень репозитория как есть, без сборки.

## Как листать

- `→`, пробел, `PgDn` — дальше. Если на слайде спрятан шаг, сначала откроется он.
- `←`, `PgUp` — назад.
- Клик по левому или правому краю, кнопки внизу, свайп.
- Число с клавиатуры — прыжок на слайд. `Home`, `End`, `R`.
- `F` — на весь экран. `N` — заметки ведущего. `?` — список клавиш.

На узком экране слайд не сжимается в почтовую марку: колонки складываются, страница прокручивается, свайп листает дальше.
